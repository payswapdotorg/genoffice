# Initial UI and view inventory

## Observed — blank Gantt workspace

The captured blank Project1 workspace is labeled Gantt Chart and consists of a
task table, Gantt chart/timescale, and timeline strip (`MP-UI-001`).

Visible table columns: Task Mode, Task Name, Duration, Start, Finish,
Predecessors, Resource Names, Add New Column (`MP-UI-002`).

Visible Task ribbon groups include View, Clipboard, Font, Schedule, Tasks,
Insert, Properties, and Editing (`MP-UI-002`).

Status-bar shortcuts visibly include Gantt Chart, Task Usage, Team Planner,
Resource Sheet, and Blank Report, plus zoom controls (`MP-UI-002`). These are
labels only; the corresponding views and transitions have not been activated.
