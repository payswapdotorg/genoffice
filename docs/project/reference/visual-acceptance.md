# Visual acceptance baseline

## VA-UI-001 — Fresh blank Gantt workspace

- **Reference image:** [`screenshots/MP-UI-001.png`](./screenshots/MP-UI-001.png)
- **Viewport:** 1936x1048 screenshot; Project window fills the captured image.
- **Visible regions:** title/Quick Access row; ribbon tabs and Task ribbon;
  timeline strip; left task table; right Gantt chart and timescale; horizontal
  and vertical scrollbars; bottom status bar, view shortcuts, and zoom slider.
- **Important visible measurements:** task-table/chart split is approximately
  46%/54% of the central pane in this capture; the timeline occupies a
  horizontal strip above the grid. These are screenshot estimates, not
  invariant product dimensions.
- **Interaction states to validate later:** selected task row/cell, active
  editor, Gantt bar selection/drag/resize, dependencies, collapsed summary,
  alternate timescales, other views, and different window sizes.
- **Evidence:** `MP-UI-001`, `MP-UI-002`.

The screenshot derivative masks the signed-in profile area. Do not use it to
infer icon details or user identity.
